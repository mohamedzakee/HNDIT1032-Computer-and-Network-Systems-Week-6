Memory basics: units, capacity, access time

Memory stores data, the instructions needed during processing, and output results. Two factors describe any memory: capacity (how much it can store, in bits or bytes) and access time (time from a read/write request until the data is available; less access time means faster memory).

RAM: DRAM and SRAM
  • RAM stores data and instructions while the computer runs. It is volatile: contents are lost at power-off and reloaded from disk at the next start.
  • Random access: any location takes the same time. Read and write at the same speed. Size in MB/GB, speed in nanoseconds.
  • Performance depends on access speed and data transfer unit size.

How DRAM works: each bit is charge on a tiny capacitor, switched by a transistor. Charged = 1, empty = 0. The charge leaks, so a refresh circuit rereads and rewrites every cell thousands of times a second.

ROM, BIOS, POST, bootstrap loader and CMOS
  • ROM is non-volatile, programmed by the manufacturer, and holds programs that stay in the computer permanently, including the BIOS and POST.
  • POST (Power-On Self-Test) checks the CPU, RAM, keyboard and drives at switch-on; faults show as beeps or messages.
  • Bootstrap loader finds the operating system on storage and loads it into RAM.
  • CMOS is battery-backed memory holding BIOS settings: date and time, boot order, hardware setup.

Flash memory: semiconductor, non-volatile, rewritable, erased electrically in blocks. No moving parts, small, low power, limited write cycles. Pen drives, memory cards, SSDs.

Secondary storage and access methods

RAM is costly, small and volatile, so a computer also needs cheap, large, non-volatile secondary storage. The CPU cannot use it directly; data is copied to RAM first.

  • Sequential access: read from the start, in order, until the data is reached. Slow. Example: magnetic tape.
  • Direct access: jump straight to the data by its address. Examples: magnetic disk, optical disk.

Magnetic tape: cheap, large, portable; sequential so slow; needs protection from dust; best for backup and archiving.

Magnetic disk: a platter coated with magnetic oxide; magnetised spot = 1, none = 0. Tracks are circles, sectors divide tracks, a cylinder is the same track on every platter. Seek time moves the head to the track, latency waits for the sector to rotate under it, transfer rate is how fast data moves. Access time = seek + latency.

Floppy disk: portable, small, cheap; 5¼-inch (360 KB–1.2 MB) and 3½-inch (up to 1.44 MB).

Optical disk: read by laser, no magnetism. CD-ROM: pits scatter light (0), lands reflect it (1), about 700 MB. DVD-ROM: denser tracks, both sides, compression, 4.7 GB per side, 9.4 GB double-sided.

CPU: ALU, control unit and registers

The CPU (microprocessor, a single IC chip) executes stored program instructions fetched from memory. Parts: ALU (arithmetic: + − × ÷; logic: >, <, = comparisons), Control Unit (coordinates I/O, tells when to fetch, what to do, where to store results, and sequences events) and registers (fastest, smallest storage, inside the CPU).
